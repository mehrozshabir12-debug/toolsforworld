File size limits explained: KB, MB and how to get under them

By Mehroz Shabir · Updated 22 October 2026

Online forms reject files that are a few kilobytes too big, and the rules are rarely explained. This guide covers what the numbers mean, how to check your file, and the quickest way to meet each kind of limit.

What KB and MB mean

File size is measured in bytes. A kilobyte (KB) is about a thousand bytes and a megabyte (MB) is about a thousand kilobytes. A typed one-page PDF is often 20–80 KB, a phone photo is usually 2–5 MB, and a phone-scanned page saved as a PDF can be 1–3 MB on its own.

Is 1 MB 1000 KB or 1024 KB?

Both are in use. Windows File Explorer counts 1 KB as 1024 bytes and 1 MB as 1024 KB. macOS Finder and most phone apps count in thousands. A file that Windows calls 1,000 KB is shown as about 1.02 MB on a Mac. Upload forms don't say which they use, so the safe rule is simple: aim a little under the limit. Our compressors do this for you, making the file just under the number you choose.

How to check a file's size

DeviceHow
WindowsRight-click the file → Properties. Look at “Size”, not “Size on disk”.
MacSelect the file and press Cmd + I.
AndroidOpen the Files app, long-press the file and choose Details or Info.
iPhoneIn the Files app, press and hold the file → Get Info. In Photos, open the photo and tap the (i) button.

Five reasons a file is still rejected

  1. Wrong type. The form wants JPG and you sent PNG or HEIC. Convert with PNG to JPG or HEIC to JPG.
  2. Pixel size as well as file size. Some forms set both, for example “200 × 230 px and under 50 KB”. Resize first, then compress.
  3. A minimum size. “Between 20 KB and 50 KB” rejects a 12 KB file. Set the target near the top of the range, such as 45 KB.
  4. The 1000 vs 1024 difference. A file at exactly the limit can fail on one site and pass on another. Go a few KB under.
  5. Unusual characters in the file name. Rename it to letters, numbers and dashes only, such as passport-photo.jpg.

Keeping quality at small sizes

  • Crop away everything the form doesn't need: background around a face, the table around a page.
  • Fewer pages means sharper pages. Remove blank or extra pages with Split PDF.
  • Scan documents in daylight, straight from above, so text is dark on clean white paper.
  • Check the result at full size before you submit. If the smallest text is hard to read, use a higher limit or fewer pages.

Questions

Is 1 MB equal to 1000 KB or 1024 KB?

It depends on the software. Windows uses 1024 KB per MB; Macs and most phones use 1000. Stay a few KB under the limit and it passes either way.

Why does my 199 KB file fail a 200 KB limit?

The site may count sizes differently from your device, or check the pixel size or file type too. Compress to a slightly lower target, such as 190 KB, and check the file type.

How do I make a file bigger to meet a minimum size?

Save the photo at a higher quality or larger pixel size. In the Image Compressor, set the target near the top of the allowed range instead of the bottom.
