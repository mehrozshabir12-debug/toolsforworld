How to check that a website never uploads your files

By Mehroz Shabir · Updated 17 October 2026

Many sites say “we respect your privacy”. With two quick tests you can see for yourself whether a tool sends your file to a server, before you trust it with a passport scan, a payslip or an assignment.

Why it matters

Most online converters work by uploading your file to their server, processing it there and sending back the result. That can be fine for a holiday photo, but not for a passport, a bank statement or medical letter. A tool that runs in your browser does the work on your own device instead, so the file never travels anywhere.

Test 1: the airplane-mode test (any phone or computer)

  1. Open the tool page and wait until it has fully loaded.
  2. Turn on airplane mode, or switch off Wi-Fi and mobile data.
  3. Choose your file and run the tool.

If you still get your result with no internet connection, the file could not have been uploaded. Try it with our image compressor or Merge PDF.

Some tools need to download extra code the first time, such as the language data for OCR or the AI model for the background remover. Run them once while online so that part is downloaded, then repeat the test offline.

Test 2: the Network tab (desktop browsers)

Every desktop browser can show you each request a page makes.

  1. Open the tool page.
  2. Open the developer tools: F12 or Ctrl + Shift + I on Windows and Linux, Cmd + Option + I on a Mac. In Safari, first turn on Settings → Advanced → “Show features for web developers”.
  3. Click the Network tab, then the clear button (a circle with a line through it) so the list is empty.
  4. Choose your file and run the tool, then look at the new rows in the list.

What an upload looks like: a request with the method POST or PUT whose request size is about as big as your file (for example a 2 MB request after you picked a 2 MB PDF). Click a row to see its size and where it went.

What is normal: downloads of scripts and fonts, and small requests to analytics or ads services. These are a few kilobytes and don't contain your file. On Tools for World you will not see a request the size of your file.

Other signs to watch for

  • A progress bar that says “Uploading…”.
  • A results page with a link that works on another device: the file must be stored on a server.
  • A notice that files are “deleted after one hour”: they were uploaded first.

None of these is wrong in itself, but they tell you the file left your device. For private documents, choose a tool that passes both tests above.

Questions

Does a padlock in the address bar mean my file stays private?

No. The padlock means the connection is encrypted. Your file can still be uploaded and stored on the website's server.

Why does the page load anything at all if files aren't uploaded?

The page downloads the code that does the work, such as the PDF library or OCR language data. Downloads come to you; nothing from your file goes out.

Does Tools for World use analytics or ads?

Yes. The site uses Google Analytics and shows ads to stay free. Those services see that a page was visited, but never your files.
