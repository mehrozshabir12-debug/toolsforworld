JPG to PNG converter

Convert JPG photos to lossless PNG files.

When to use PNG

PNG is lossless, so it suits screenshots, graphics and images you will edit again. It does not make a JPG sharper, and the file will be larger.

How to convert JPG to PNG

  1. Choose one or more JPG photos.
  2. Press Convert to PNG.
  3. Download each PNG, or all of them as one ZIP.

Good reasons to convert

  • An app, printer or website only accepts PNG.
  • You will edit and save the image many times: PNG doesn't lose quality each time it is saved.
  • You plan to add transparency or layers in an editor.

For a transparent background, use the Background Remover, which outputs a transparent PNG.

Questions

Does JPG to PNG make the background transparent?

No. The image stays exactly as it is. Use the Background Remover to get a transparent PNG.

Why is the PNG so much bigger?

PNG is lossless, so it stores every pixel exactly. Photos are usually 2–5 times larger as PNG than as JPG.
