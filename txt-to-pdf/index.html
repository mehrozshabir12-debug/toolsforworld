TXT to PDF converter

Turn plain text files (.txt) into clean, printable PDFs. Long lines wrap neatly, pages break automatically, and your file is never uploaded.

How to convert TXT to PDF

  1. Choose one or more .txt files (Markdown, CSV and log files work too).
  2. Pick a font, size and page size.
  3. Press Convert to PDF and download one PDF per text file.

What the PDF looks like

  • Each line of your file starts on a new line in the PDF; blank lines are kept, so paragraphs stay separate.
  • Lines longer than the page width wrap at a space, and very long words or links are split so nothing runs off the page.
  • Pages have 2 cm margins and break automatically when one is full.
  • Tabs become four spaces. Pick Monospace to keep columns, code and ASCII tables lined up.

Languages and characters

Text in Latin letters (English, Spanish, French, German and so on) is written into the PDF as real text, so you can select, copy and search it. Arabic, Urdu, Hindi, Chinese, Cyrillic and other scripts are drawn onto the pages as images using your device's fonts, so every character shows correctly; that text can't be selected afterwards.

When to use it

  • Submitting notes, code or logs to a portal that only accepts PDF.
  • Printing a long text file with proper page breaks.
  • Sharing a README, lyrics you wrote yourself, a script or a transcript as one tidy document.

Have a Word document instead? Use Word to PDF. Need the text from a photo first? Image to Text (OCR) turns it into a .txt file.

Questions

Is TXT to PDF free?

Yes, with no limits, sign-up or watermark.

Can I select and copy the text in the PDF?

Yes for text in Latin letters. Other scripts are drawn as page images so they display correctly, and can't be selected.

Does it keep my line breaks?

Yes. Every line break and blank line in the .txt file is kept, and long lines wrap to fit the page.

Can I convert several text files at once?

Yes. Choose several files and you get one PDF for each.

Is my file uploaded?

No. The PDF is made in your browser, so the text never leaves your device.
