# Backlink outreach log

Rules (owner, 17 Oct 2026):
- Send only from hello@toolsforworld.com (Gmail web, From = "Tools For World <hello@toolsforworld.com>"). Never from the personal Gmail.
- Never include anything about the owner (name, city, student status). Sign off as "The Tools for World team".
- Use plain https://toolsforworld.com links. Do not create drafts with the Gmail connector: it rewrites links into google.com/url redirects.
- Every email ends with: "If you'd rather not hear from us again, just reply and let us know." (Australian Spam Act: identify the sender, offer an opt-out.)
- Only contact addresses that the site itself publishes for contact/press/suggestions. Never guess addresses.
- Only relevant pages: independent articles, resource pages, edtech/student blogs and tool directories. Skip competitor tool sites, paid/advertorial placements, link sellers, and sites promoting academic cheating or AI-detection evasion.
- Never contact the same site twice. Follow up at most once, after 7+ days, only if there was no reply.
- Never pay for links.
