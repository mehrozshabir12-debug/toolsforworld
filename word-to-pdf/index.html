Word to PDF converter

Convert a Word document (.docx) to PDF without uploading it. Ideal for CVs, cover letters, forms and assignments.

How to convert Word to PDF

  1. Choose your .docx file.
  2. Pick the page size and orientation.
  3. Press Convert to PDF and download it.
Text, headings, lists, pictures and simple tables convert well. Complex layouts (columns, text boxes, headers and footers, special fonts) may look different from Word. For those, use Word's File → Save As → PDF.

Want text you can select and search in the PDF? After converting, use “Print / Save as PDF” and choose “Save as PDF” as the printer.

Why send a PDF instead of a Word file?

A PDF looks the same on every phone and computer, it can't be changed by accident, and almost every job portal, university system and government form accepts it. That's why CVs, cover letters, assignments and signed letters are normally sent as PDF.

Getting the best result

  • Use common fonts (Calibri, Arial, Times New Roman). Unusual fonts may be replaced.
  • Keep the layout simple: one column, normal tables and pictures placed "in line with text" convert most faithfully.
  • Check page breaks in the PDF preview before you send it, especially for one-page CVs.
  • Name the file clearly, for example Firstname-Lastname-CV.pdf.

Need the final PDF smaller for an upload limit? Run it through Compress PDF. Need to join it with a transcript or certificate? Use Merge PDF.

Questions

Does it work with .doc files?

Only .docx. Open an old .doc in Word or Google Docs and save it as .docx first.

Is my document uploaded?

No, it never leaves your device.

Will my hyperlinks still work?

Use the “Print / Save as PDF” option for a PDF with selectable text; links usually survive that route. The direct conversion produces page images.

Can I convert Google Docs?

Yes. In Google Docs choose File → Download → Microsoft Word (.docx), then convert that file here.
