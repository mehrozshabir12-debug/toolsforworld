# Tools for World

Free online PDF, image, text and audio tools that run entirely in the browser — no upload, no sign-up.
Live site: https://toolsforworld.com

- Static site served by GitHub Pages (custom domain in `CNAME`).
- Pages are generated by `build.py` from the tool list in `tools_list.py`; shared code is in `assets/`.
- Every tool is tested in a real browser by `.github/workflows/test.yml` (results on the `test-results` branch).
