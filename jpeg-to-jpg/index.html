JPEG to JPG converter

Change .jpeg (and .jpe) files to .jpg in one click, for forms and apps that only accept .jpg. The picture stays exactly the same.

How to convert JPEG to JPG

  1. Choose one or more .jpeg files.
  2. Press Convert to JPG.
  3. Download each .jpg, or all of them as one ZIP.

JPEG vs JPG: is there a difference?

No. JPEG and JPG are the same image format. The format is named after the Joint Photographic Experts Group; the shorter .jpg ending comes from early versions of Windows, which only allowed three letters after the dot. Today both endings hold identical data, but some upload forms, government portals and older programs check the file name and reject .jpeg.

What this tool does

It confirms each file really is a JPEG and saves the same data under a .jpg name. There is no re-compression, so the quality and file size don't change. Files that aren't really JPEGs inside are converted to a proper JPG at high quality.

Other ways to do it

  • Windows: turn on "File name extensions" in File Explorer's View menu, then rename the file from photo.jpeg to photo.jpg.
  • Mac: select the file, choose File → Get Info, and change the ending under Name & Extension.
  • Phone: renaming endings is awkward in most phone file apps, so converting here is usually quicker.

Questions

Is JPEG the same as JPG?

Yes. They are two spellings of the same format and the files are identical inside.

Does converting JPEG to JPG lower the quality?

No. The picture data is not re-compressed, so nothing changes except the file name.

Why does a form reject my .jpeg file?

Some websites only check for the .jpg ending. Converting here gives the file that ending without changing the picture.

Can I convert several files at once?

Yes. Choose many files and download them separately or as one ZIP.

Is my photo uploaded?

No. The conversion runs in your browser.
