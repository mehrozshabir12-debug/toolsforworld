How to resize an image

  1. Choose one or more images.
  2. Enter a width or height, or a percentage.
  3. Press Resize.

Common sizes: 1080 × 1080 for Instagram posts, 1200 × 630 for link previews, 1920 × 1080 for HD.

Need a size in KB, not pixels?

Forms that say “resize image to 20 KB” mean the file size. That's a job for the compressor: 20 KB, 50 KB, 100 KB or any size you type.

Pixels, aspect ratio and cropping

Resizing changes how many pixels wide and tall an image is. With “keep ratio” on, you set one side and the other follows, so faces and logos don't stretch. If you need a different shape, such as a square from a portrait photo, the picture has to be cropped or padded, because squeezing it would distort it.

Questions

How do I resize an image to 20 KB or 100 KB?

KB is file size, not width and height. Use Compress Image to 20 KB or 100 KB: it lowers the file size and only shrinks the pixels if it has to.

Will resizing make my photo blurry?

Making a photo smaller keeps it sharp. Making it much larger than the original can look soft, because no new detail is added.

Does resizing reduce the file size?

Making an image smaller in pixels usually makes the file smaller too. For an exact KB limit, use the Image Compressor.

Can I resize several images to the same size?

Yes. Choose several files and they are all resized with the same settings.
