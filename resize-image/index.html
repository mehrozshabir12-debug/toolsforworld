Image resizer

Set an exact size in pixels or scale by percent. Keep the ratio so photos do not stretch.

How to resize an image

  1. Choose one or more images.
  2. Enter a width or height, or a percentage.
  3. Press Resize.

Common sizes: 1080 × 1080 for Instagram posts, 1200 × 630 for link previews, 1920 × 1080 for HD.
