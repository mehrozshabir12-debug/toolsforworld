Merge PDF

Combine several PDF files into one, in the order you choose. Use the arrows to reorder.

How to merge PDF files

  1. Choose two or more PDFs.
  2. Put them in order with the ▲ ▼ arrows.
  3. Press Merge PDFs and download the combined file.

Bookmarks and form fields are not kept; pages, text and images are.

Questions

Can I merge password-protected PDFs?

No. Remove the password first in a PDF reader.

Is there a limit on how many PDFs?

No fixed limit.
