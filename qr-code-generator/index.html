How to make a QR code

  1. Type or paste a link, text, phone number or Wi-Fi details.
  2. Choose the size and colours.
  3. Download the PNG and print or share it.

Tips

  • Keep strong contrast: dark code on a light background scans best.
  • Use “High” error correction if the code will be printed small or might get scratched.
  • Always test-scan before you print hundreds of copies.

Static QR codes that never expire

The code made here stores your link or text directly inside the pattern. There's no redirect through our server, so it keeps working as long as the link itself works, with no subscription. The trade-off is that you can't change where it points after printing; to change it, make a new code.

Making a code that scans every time

  • Keep strong contrast: dark code on a light background. Light-on-dark codes fail on some phones.
  • Leave a clear margin around the code.
  • Print it at least 2 × 2 cm, larger if people scan from a distance.
  • Use higher error correction if the code may get scratched or partly covered.
  • Test it with two different phones before printing hundreds.

Questions

Do these QR codes expire?

No. The data is stored in the code itself, so it works forever.

Can I make a Wi-Fi QR code?

Yes. Press the Wi-Fi button and replace the network name and password.

Can I track how many people scan it?

No. Static codes don't pass through a server, so there is no tracking. That's also what keeps them private.

Can I use the QR code commercially?

Yes. Codes you make here are yours to use on menus, flyers, packaging and cards.
